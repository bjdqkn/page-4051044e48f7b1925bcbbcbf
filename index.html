客户端怎么选

强调客户端，是因为同样的订阅链接，落到不同系统上体验完全不同。先确认系统与导入方式，再下载对应应用：桌面端适合长时间挂起与规则编辑，移动端适合出门外网与流媒体切换。官方下载入口集中在下方模块，请勿从来路不明的镜像获取安装包。

SCENES

使用场景

按任务选客户端，而不是先被套餐名带着走。

  • 资料与检索浏览器走代理规则，适合论文、文档站点与开发者文档；桌面客户端便于按域名分流，避免国内站点绕行。
  • 流媒体观看是否解锁、解锁范围以套餐说明为准。建议使用支持节点切换与延迟显示的客户端，便于换线路而不是反复开关。
  • 游戏与低延迟需要稳定会话的场景，优先固定一条线路并关闭频繁自动切换；具体是否提供游戏向优化，请直接对照套餐条目。
  • 出差多设备同一订阅可写入多台设备，但同时在线台数受套餐约束。出门以手机客户端为主，回到工位再切回电脑。
  • 小团队协作需要统一路由策略时，由一人管理订阅更新，其余成员只负责在客户端里更新配置，减少各改各的规则文件。
STEPS

操作说明

从开通到连上，五步即可走完；任何一步卡住，先回到客户端是否匹配系统。

  1. 确认套餐边界

    打开套餐区，看清流量周期与可同时在线的设备数量。不要在正文里寻找价格表——数值只出现在套餐模块，以免版本不一致。

  2. 取得机场订阅

    开通后在用户中心复制订阅链接（或扫描导入）。链接相当于配置地址，请勿公开发布或提交到公开仓库。

  3. 下载对应客户端

    回到本页客户端模块，按系统选择官方下载。安装完成后先不要急着搜公共节点，龙猫云使用的是你自己的订阅。

  4. 导入并更新

    在客户端选择「订阅 / URL 导入」，粘贴链接，执行一次更新。看到节点列表即表示导入成功；若列表为空，检查链接是否完整、客户端是否支持该订阅格式。

  5. 连接与分流

    选择节点连接。建议将国内常用域名设为直连，把需要网络加速的应用或网站走代理。之后日常只需打开客户端、保持订阅定期更新。

FAQ

常见问题

龙猫云是什么？和普通 VPN 有何不同？

龙猫云以机场订阅的方式提供网络加速：你在官网开通后获得订阅链接，再导入自选客户端。它更接近可更新的节点配置源，而不是单一 App 内置线路。具体线路能力以套餐模块为准。

客户端必须用哪一款？

没有唯一指定软件。原则是：系统匹配、能导入订阅、能更新节点。桌面与移动端可以同时配置同一订阅，只要不超过套餐允许的同时在线数量。下载请使用本页客户端区域的官方下载。

如何完成第一次连接？

选套餐 → 复制订阅 → 安装客户端 → 导入 URL → 更新节点 → 连接。若导入失败，优先检查链接前后空格、客户端协议支持，以及系统是否拦截了本地代理权限。

流量或设备不够用怎么办？

在套餐区对比更高档方案。正文不重复具体额度，避免与实时展示不一致。更换套餐后，通常只需在客户端里更新订阅，不必卸载重装。

可以用在流媒体或游戏上吗？

部分套餐会写明流媒体或游戏相关能力。能否播放、延迟是否可接受，取决于你所选套餐与当时线路，请以套餐说明为准，本页不编造解锁名单或延迟数字。

订阅链接泄露了怎么办？

立即在用户中心重置订阅。重置后旧链接失效，已导入的设备需要重新填写新地址。不要把订阅发到群文件或截图公开。
